# Personal Expense Tracker

Personal Expense Tracker is a simple desktop application developed using **C# Windows Forms (.NET Framework)**. It helps users manage their daily expenses through an easy-to-use multi-form interface.

## Features

- **View Expenses:** Display all expenses in a DataGridView.
- **Add Expense:** Add new expenses using a separate form.
- **Edit Expense:** Update existing expense details.
- **Category Selection:** Choose categories such as Food, Travel, Shopping, Education, and Other.
- **Date Selection:** Select the expense date.
- **Total Calculation:** Automatically calculate the total amount of all expenses.
- **Input Validation:** Prevent empty names and invalid amounts.

## Technologies Used

- C#
- Windows Forms
- .NET Framework 4.8
- Visual Studio
